List of available ElevenLabs TTS voices for the [Call.say](/reference/voxengine/call#say) and [VoxEngine.createTTSPlayer](/reference/voxengine/voxengine#createttsplayer) methods. Depending on the voice, different technologies are used to make synthesized voices sound as close as possible to live human voices. Please note that using these text-to-speech capabilities are charged according to the [pricing](https://voximplant.com/pricing).
