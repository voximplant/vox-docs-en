Jev provides a VoxEngine client for the TypeSafe System One API. A scenario sends text, and optional images, and receives typed answers for routing, triage, or scoring.

This client does not take call audio. Use `Jev.createSystemOneClient(...)` to keep one connection open, then call `systemOne` for each decision.

Build questions with `noul`, `choice`, `score`, and `box`. Use the `jev-preview` model when a request includes `box`.

## Usage

Add the module before using the namespace:

```js
require(Modules.Jev);
```

Create the client, wait for ConnectorInformation, then send systemOne requests on the same connection. A failed request does not close the client.

| Property | Type | Req. | Description |
| --- | --- | --- | --- |
| <a id="systemoneclientparameters-apikey" /> `apiKey` | `string` | ✓ | The TypeSafe API key. Sent as `Authorization: Bearer` on each System One request. |
| <a id="systemoneclientparameters-baseurl" /> `baseUrl` | `string` | ✗ | Overrides the TypeSafe API host. The default host is `https://api.typesafe.ai`. |
| <a id="systemoneclientparameters-longcontext" /> `longContext` | `boolean` | ✗ | When true, each request sends `TypeSafe-Danger-Zone-Long-Context: true` unless a call overrides it. |
| <a id="systemoneclientparameters-onwebsocketclose" /> <code>onWebSocket<wbr />Close</code> | <code>(event: object) => void</code> | ✗ | _inherited from _VoiceAIClientParameters_ A callback function that is called when the [WebSocket](/reference/voxengine/websocket) connection is closed. |
| <a id="systemoneclientparameters-privacy" /> `privacy` | `boolean` | ✗ | _inherited from _WebSocketBasedClientParameters_ Whether to enable the privacy functionality. If privacy is enabled, the logging for the WebSocket connection is disabled. NOTE: the default value is **false**. |
| <a id="systemoneclientparameters-statistics" /> `statistics` | `boolean` | ✗ | _inherited from _WebSocketBasedClientParameters_ Enables statistics functionality. |
| <a id="systemoneclientparameters-trace" /> `trace` | `boolean` | ✗ | _inherited from _WebSocketBasedClientParameters_ Whether to enable the tracing functionality.
