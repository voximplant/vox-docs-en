## Classes

- [MinWordsStart](/reference/voxengine/agentic/voice-dsp-strategies/min-words-start) — A start strategy that requires the user to speak a minimum number of words before triggering a turn start.
- [SpeechTimeoutStop](/reference/voxengine/agentic/voice-dsp-strategies/speech-timeout-stop) — A stop strategy that uses a configurable timeout to determine if the user is done speaking.
- [TranscriptionStart](/reference/voxengine/agentic/voice-dsp-strategies/transcription-start) — A start strategy that triggers a user turn start when a transcription is received.
- [TurnDetectorStop](/reference/voxengine/agentic/voice-dsp-strategies/turn-detector-stop) — A stop strategy that uses the AI-powered turn detection model to determine if the user is done speaking.
- [VADStart](/reference/voxengine/agentic/voice-dsp-strategies/vad-start) — A start strategy that triggers a user turn start based on Voice Activity Detection.
