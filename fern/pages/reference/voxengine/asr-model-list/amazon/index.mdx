List of Amazon ASR models. Can be passed via the `ASRParameters.model` parameter.
Add the following line to your scenario code to use the enum:
```
require(Modules.ASR);
```

## Constants

| Name | Type | Description |
| --- | --- | --- |
| <a id="default" /> `DEFAULT` | `ASRModel` | Best for audio that originated from a phone call (typically recorded at a 8khz sampling rate). |
