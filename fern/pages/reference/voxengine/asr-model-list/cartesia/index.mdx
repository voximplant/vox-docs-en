subtitle: List of Cartesia ASR models.
---

List of Cartesia ASR models. Can be passed via the `ASRParameters.model` parameter.
Add the following line to your scenario code to use the enum:
```
require(Modules.ASR);
```

## Constants

| Name | Type | Description |
| --- | --- | --- |
| <a id="default" /> `DEFAULT` | `ASRModel` | The default **ink-2** model. English only. |
| <a id="ink2" /> `ink2` | `ASRModel` | Production model. English only. |
| <a id="inkpreview" /> `ink_preview` | `ASRModel` | Preview model. Automatically detects English, French, Hindi, Japanese, and Spanish. |
