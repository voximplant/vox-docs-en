List of Deepgram ASR models. Can be passed via the `ASRParameters.model` parameter.
Add the following line to your scenario code to use the enum:
```
require(Modules.ASR);
```

## Constants

| Name | Type | Description |
| --- | --- | --- |
| <a id="default" /> `DEFAULT` | `ASRModel` | The default **General** model. |
| <a id="general" /> `general` | `ASRModel` | Optimized for everyday audio processing. |
| <a id="generalenhanced" /> `general_enhanced` | `ASRModel` | Optimized for everyday audio processing. Applies the newest ASR module with higher accuracy. |
| <a id="meeting" /> `meeting` | `ASRModel` | Optimized for conference room settings, which include multiple speakers with a single microphone. |
| <a id="meetingenhanced" /> `meeting_enhanced` | `ASRModel` | Optimized for conference room settings, which include multiple speakers with a single microphone. Applies the newest ASR module with higher accuracy. |
| <a id="phonecall" /> `phonecall` | `ASRModel` | Optimized for low-bandwidth audio phone calls. |
| <a id="phonecallenhanced" /> `phonecall_enhanced` | `ASRModel` | Optimized for low-bandwidth audio phone calls. Applies the newest ASR module with higher accuracy. |
| <a id="voicemail" /> `voicemail` | `ASRModel` | Optimized for low-bandwidth audio clips with a single speaker. Derived from the phonecall model. |
| <a id="finance" /> `finance` | `ASRModel` | Optimized for multiple speakers with varying audio quality, such as might be found on a typical earnings call. Vocabulary is heavily finance oriented. |
| <a id="financeenhanced" /> `finance_enhanced` | `ASRModel` | Optimized for multiple speakers with varying audio quality, such as might be found on a typical earnings call. Vocabulary is heavily finance oriented. Applies the newest ASR module with higher accuracy. |
