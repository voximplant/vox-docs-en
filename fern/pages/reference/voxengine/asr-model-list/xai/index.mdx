List of xAI ASR models. Can be passed via the `ASRParameters.model` parameter.
Add the following line to your scenario code to use the enum:
```
require(Modules.ASR);
```

## Constants

| Name | Type | Description |
| --- | --- | --- |
| <a id="default" /> `DEFAULT` | `ASRModel` | The default **grok-voice-transcribe-2.0** model. |
