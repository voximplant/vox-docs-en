XAI provides VoxEngine clients for the xAI Grok Voice Agent API and Realtime TTS over WebSocket.

Use `XAI.createVoiceAgentAPIClient(...)` to create a `VoiceAgentAPIClient` for voice-agent scenarios. After the client is created, call methods such as `sendMediaTo`, `responseCreate`, and `addEventListener` on that client instance.

Use `XAI.createRealtimeTTSPlayer(...)` when you only need realtime text-to-speech playback.

## Usage

Add the module before using the namespace:

```js
require(Modules.XAI);
```

Create the client, bridge media, and listen for both WebSocket media events and Voice Agent API events.

## Factory functions

### <Icon icon="fa-duotone fa-brackets-curly" /> createRealtimeTTSPlayer

Creates a new [XAI.RealtimeTTSPlayer](/reference/voxengine/xai/realtime-tts-player) instance. You can attach media streams later via the `XAI.RealtimeTTSPlayer.sendMediaTo` or `VoxEngine.sendMediaBetween` methods.

```ts
createRealtimeTTSPlayer(parameters?: {
  statistics?: boolean;
  trace?: boolean;
  privacy?: boolean;
  connectionParameters?: Object;
  apiKey?: string;
}): RealtimeTTSPlayer
```

The optional `parameters` object is typed as <code>XAI.RealtimeTTS<wbr />Player<wbr />Parameters</code>.

**Parameters**

| Parameter | Type | Req. | Description |
| --- | --- | --- | --- |
| `parameters` | <code>RealtimeTTS<wbr />Player<wbr />Parameters</code> | ✗ | [XAI.RealtimeTTSPlayer](/reference/voxengine/xai/realtime-tts-player) parameters. Can be passed as arguments to the `XAI.createRealtimeTTSPlayer` method. |
| ↳ `statistics` | `boolean` | ✗ | Enables statistics functionality. |
| ↳ `trace` | `boolean` | ✗ | Whether to enable the tracing functionality. If tracing is enabled, a URL to the trace file appears in the 'websocket.created' message. The file contains all sent and received WebSocket messages in the plain text format. The file is uploaded to the S3 storage. NOTE: enable this only for diagnostic purposes. You can provide the trace file to our support team to help investigate issues. |
| ↳ `privacy` | `boolean` | ✗ | Whether to enable the privacy functionality. If privacy is enabled, the logging for the WebSocket connection is disabled. NOTE: the default value is **false**. |
| ↳ <code>connection<wbr />Parameters</code> | `Object` | ✗ | Object to provide parameters for the xAI WebSocket connection. Must contain `voice` and `language`. Find more information in the [documentation](https://docs.x.ai/developers/model-capabilities/audio/text-to-speech#connection). VoxEngine requires voice and language and forwards speed, optimize_streaming_latency, and text_normalization. Audio output is fixed to PCM at 16000 Hz. The partner API also documents codec, sample_rate, bit_rate, and with_timestamps for direct provider use; these are not supported adapter controls. |
| ↳ <code>connection<wbr />Parameters.<wbr />voice</code> | `string` | ✓ | Built-in xAI voice name or custom voice ID. VoxEngine requires this field when `connectionParameters` is supplied. |
| ↳ <code>connection<wbr />Parameters.<wbr />language</code> | `string` | ✓ | BCP-47 language code or `auto` for automatic language detection. VoxEngine requires this field when `connectionParameters` is supplied. |
| ↳ <code>connection<wbr />Parameters.<wbr />speed</code> | `number` | ✗ | Speech speed multiplier from `0.7` to `1.5`. Defaults to `1.0`. |
| ↳ <code>connection<wbr />Parameters.<wbr />optimize_<wbr />streaming_<wbr />latency</code> | <code>0 \| 1 \| 2</code> | ✗ | Streaming latency optimization. `0` favors quality, `1` moderately reduces time to first audio, and `2` is the most aggressive. Defaults to `0`. |
| ↳ <code>connection<wbr />Parameters.<wbr />text_<wbr />normalization</code> | `boolean` | ✗ | Normalize written text such as numbers and abbreviations into spoken form. Defaults to `false`. |
| ↳ `apiKey` | `string` | ✗ | xAI API key. Use your xAI API key if you have your own xAI account. |

**Returns**

| Type | Description |
| --- | --- |
| <code>RealtimeTTS<wbr />Player</code> | The requested `RealtimeTTSPlayer` value. |

### <Icon icon="fa-duotone fa-brackets-curly" /> createVoiceAgentAPIClient

Creates a new [XAI.VoiceAgentAPIClient](/reference/voxengine/xai#voiceagentapiclient) instance.

```ts
createVoiceAgentAPIClient(parameters: {
  statistics?: boolean;
  trace?: boolean;
  privacy?: boolean;
  onWebSocketClose?: (event: object) => void;
  xAIApiKey: string;
  model?: string;
  conversationId?: string;
  reasoningEffort?: string;
}): Promise<XAI.VoiceAgentAPIClient>
```

The required `parameters` object is typed as <code>XAI.VoiceAgent<wbr />APIClient<wbr />Parameters</code>.

**Parameters**

| Parameter | Type | Req. | Description |
| --- | --- | --- | --- |
| `parameters` | <code>VoiceAgent<wbr />APIClient<wbr />Parameters</code> | ✓ | [XAI.VoiceAgentAPIClient](/reference/voxengine/xai#voiceagentapiclient) parameters. Can be passed as arguments to the `XAI.createVoiceAgentAPIClient` method. |
| ↳ `statistics` | `boolean` | ✗ | Enables statistics functionality. |
| ↳ `trace` | `boolean` | ✗ | Whether to enable the tracing functionality. If tracing is enabled, a URL to the trace file appears in the 'websocket.created' message. The file contains all sent and received WebSocket messages in the plain text format. The file is uploaded to the S3 storage. NOTE: enable this only for diagnostic purposes. You can provide the trace file to our support team to help investigate issues. |
| ↳ `privacy` | `boolean` | ✗ | Whether to enable the privacy functionality. If privacy is enabled, the logging for the WebSocket connection is disabled. NOTE: the default value is **false**. |
| ↳ <code>onWebSocket<wbr />Close</code> | <code>(event: object) => void</code> | ✗ | A callback function that is called when the [WebSocket](/reference/voxengine/websocket) connection is closed. |
| ↳ `xAIApiKey` | `string` | ✓ | The xAI API key for the XAI VoiceAgent API. |
| ↳ `model` | `string` | ✗ | The model to use for the XAI VoiceAgent API. [https://docs.x.ai/developers/model-capabilities/audio/voice-agent#model-selection](https://docs.x.ai/developers/model-capabilities/audio/voice-agent#model-selection). Note: The default value is **grok-voice-fast-1.0**. |
| ↳ <code>conversation<wbr />Id</code> | `string` | ✗ | Conversation id from a previous `XAI.VoiceAgentAPIEvents.ConversationCreated` event. Pass it when creating a new client to resume the session after a WebSocket disconnect (xAI [session resumption](https://docs.x.ai/docs/guides/voice/agent#session-resumption)). Enable caching with `resumption: { enabled: true }` in `XAI.VoiceAgentAPIClient.sessionUpdate`. |
| ↳ <code>reasoning<wbr />Effort</code> | `string` | ✗ | Controls whether the model uses reasoning (`high` \| `none`). Passed as the WebSocket `reasoning.effort` query parameter. Defaults to `high` on the xAI side when omitted. |

**Returns**

| Type | Description |
| --- | --- |
| <code>Promise&lt;XAI.VoiceAgentAPIClient&gt;</code> | Resolves to the [`XAI.VoiceAgentAPIClient`](#voiceagentapiclient) instance. |
