title: RealtimeTTSPlayer
subtitle: Realtime TTS player for xAI Grok speech synthesis in VoxEngine.
---

XAI provides a real-time Grok TTS player that streams generated audio to calls, WebSockets, and other VoxEngine media units.

Use `XAI.createRealtimeTTSPlayer(...)` to create a `RealtimeTTSPlayer`. Send `text.delta`, `text.done`, and `text.clear` messages to stream utterances and handle barge-in without reconnecting.

VoxEngine uses PCM audio at 16000 Hz. Keep the adapter audio format when configuring the xAI connection.

### <Icon icon="fa-duotone fa-function" /> send

Send message object to the xAI provider context.

```ts
send(parameters: Object): void
```

**Parameters**

| Parameter | Type | Req. | Description |
| --- | --- | --- | --- |
| `parameters` | `Object` | ✓ | Send `text.delta` to append text, `text.done` to finish the current utterance, or `text.clear` to cancel it for barge-in. The WebSocket remains open for subsequent utterances. Preserve spaces and punctuation across text.delta chunks. For VoxEngine barge-in, clearBuffer() cancels the provider utterance and clears queued playback audio.  See the [partner API reference](https://docs.x.ai/developers/model-capabilities/audio/text-to-speech#streaming-tts-websocket). |

**Returns**

| Type | Description |
| --- | --- |
| `void` | Does not return a value. |

Example `parameters` messages:

**`text.delta`**

```json
{
  "type": "text.delta",
  "delta": "Hello from Grok TTS."
}
```

**`text.done`**

```json
{
  "type": "text.done"
}
```

**`text.clear`**

```json
{
  "type": "text.clear"
}
```

<Accordion title="AudioChunksPlaybackFinished">

Triggered when an audio chunk playback is finished. Note that this event is triggered only for RealtimeTTSPlayer instances.

For [VoxTTS.RealtimeTTSPlayer](/reference/voxengine/vox-tts/realtime-tts-player), the optional **final** field indicates whether the completed flush ends the current phrase or is an intermediate auto-flush.

Event constant: `PlayerEvents.AudioChunksPlaybackFinished`

**Payload**

| Field | Type | Req. | Description |
| --- | --- | --- | --- |
| `player` | <code>RealtimeTTS<wbr />Player</code> | ✓ | The [XAI.RealtimeTTSPlayer](#realtimettsplayer) instance that emitted the event. |
| <code>timeToFirst<wbr />Byte</code> | `number` | ✓ | Time to first byte (TTFB) in milliseconds. Represents the delay between sending the request and receiving the first byte of audio data. |
| `final` | `boolean` | ✗ | Whether the completed flush ends the current phrase. Present only for [VoxTTS.RealtimeTTSPlayer](/reference/voxengine/vox-tts/realtime-tts-player) (`true` or `false`); omitted for other RealtimeTTS providers. - `true` — final (normal) flush; phrase playback is complete. - `false` — intermediate auto-flush; more audio is expected. |
</Accordion>
