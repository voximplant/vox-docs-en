## Values

<a id="websocketmediastarted" />
<ParamField path="WebSocketMediaStarted" type="'QwenCloud.Events.WebSocketMediaStarted'">
Triggered when the audio stream sent through a Qwen Cloud WebSocket starts playing.
</ParamField>

<a id="websocketmediaended" />
<ParamField path="WebSocketMediaEnded" type="'QwenCloud.Events.WebSocketMediaEnded'">
Triggered after the end of the audio stream sent through a Qwen Cloud WebSocket (**1 second of silence**).
</ParamField>
