The AI module provides additional methods that use Artificial Intelligence. These methods allow solving business tasks in a more productive way.
Add the following line to your scenario code to use the namespace:
```
require(Modules.AI);
```

## Functions

### createDialogflow

Creates a new [AI.DialogflowInstance](/reference/voxengine/ai/dialogflow-instance) which provides resources for exchanging data with the Dialogflow API, handling specified events, etc. You can attach media streams later via the `AI.DialogflowInstance.sendMediaTo` or `VoxEngine.sendMediaBetween` methods.
Add the following line to your scenario code to use the function:
```
require(Modules.AI);
```

```ts
createDialogflow(parameters: DialogflowSettings): DialogflowInstance
```

<ParamField path="parameters" type="DialogflowSettings" required />

### DialogflowStreamingRecognitionResult

Contains a speech recognition result, corresponding to a portion of the audio that is currently being processed; or an indication that this is the end of the single requested utterance.
Add the following line to your scenario code to use the interface:
```
require(Modules.AI);
```

<a id="dialogflowstreamingrecognitionresult-confidence" />
<ParamField path="confidence" type="number">
The Speech confidence between **0.0** and **1.0** for the current portion of audio. The default of **0.0** is a sentinel value indicating that confidence was not set. Note that the field is typically only provided if **is_final: true**, and you should not rely on it being accurate or even set.
</ParamField>

<a id="dialogflowstreamingrecognitionresult-isfinal" />
<ParamField path="isFinal" type="boolean">
The default of **0.0** is a sentinel value indicating confidence was not set. If **false**, the *StreamingRecognitionResult* represents an interim result that may change. If **true**, the recognizer does not return any further hypotheses about this piece of the audio.
</ParamField>

<a id="dialogflowstreamingrecognitionresult-messagetype" />

Type of the result message.

<a id="dialogflowstreamingrecognitionresult-transcript" />

### DialogflowSynthesizeSpeechConfig

Configuration of how speech should be synthesized.
Add the following line to your scenario code to use the interface:
```
require(Modules.AI);
```

<a id="dialogflowsynthesizespeechconfig-effectsprofileid" />
<ParamField path="effectsProfileId" type="string[]">
_optional_

Optional. An identifier which selects 'audio effects' profiles that are applied on (post synthesized) text to speech. Effects are applied on top of each other in the order they are given.
</ParamField>

<a id="dialogflowsynthesizespeechconfig-pitch" />
<ParamField path="pitch" type="number">
_optional_

Optional. Speaking pitch, in the range [-20.0, 20.0]. 20 means increase 20 semitones from the original pitch. -20 means decrease 20 semitones from the original pitch.
</ParamField>

<a id="dialogflowsynthesizespeechconfig-speakingrate" />
<ParamField path="speakingRate" type="number">
_optional_

Optional. Speaking rate/speed, in the range [0.25, 4.0]. 1.0 is the normal native speed supported by the specific voice. 2.0 is twice as fast, and 0.5 is half as fast. If not set (0.0), defaults to the native 1.0 speed. Any other values &lt; 0.25 or > 4.0 return an error.
</ParamField>

<a id="dialogflowsynthesizespeechconfig-voice" />
<ParamField path="voice" type="DialogflowVoiceSelectionParameters">
_optional_

Optional. The desired voice of the synthesized audio.
</ParamField>

<a id="dialogflowsynthesizespeechconfig-volumegaindb" />
<ParamField path="volumeGainDb" type="number">
_optional_

Optional. Volume gain (in dB) of the normal native volume supported by the specific voice, in the range [-96.0, 16.0]. If not set, or set to a value of 0.0 (dB), plays at normal native signal amplitude. A value of -6.0 (dB) plays at approximately half the amplitude of the normal native signal amplitude. A value of +6.0 (dB) plays at approximately twice the amplitude of the normal native signal amplitude. We strongly recommend not to exceed +10 (dB) as there is usually no effective increase in loudness for any value greater than that.
</ParamField>
