## Methods

### addEventListener

Adds a handler for the specified [AI.Events](/reference/voxengine/ai/events). Use only functions as handlers; anything except a function leads to the error and scenario termination when a handler is called.

```ts
addEventListener(event: AI.Events | T, callback: (event: AI._Events[T]) => any): void
```

**Parameters**

<ParamField path="event" type="AI.Events | T" required />

<ParamField path="callback" type="(event: AI._Events[T]) => any" required />

### addMarker

Add a Dialogflow speech synthesis playback marker. The [AI.Events.DialogflowPlaybackMarkerReached](/reference/voxengine/ai/events#dialogflowplaybackmarkerreached) event is triggered when the marker is reached.

```ts
addMarker(offset: number): void
```

**Parameters**

<ParamField path="offset" type="number" required />

### id

```ts
id(): string
```

**Parameters**

<ParamField path="event" type="AI.Events | T" required />

### sendQuery

Send a query to the DialogFlow instance. You can send either a text string up to **256 characters** or an event object with the event name and additional data.


<ParamField path="dialogflowQuery" type="DialogflowQueryInput" required />
