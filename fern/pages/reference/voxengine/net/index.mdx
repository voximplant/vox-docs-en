## Functions

### httpRequest

Performs a regular HTTP or HTTPS request. To perform an HTTPS request, insert "https://" at the URL's beginning. The default request method is **GET**, TCP connect timeout is **6** seconds and total request timeout is **90** seconds. Learn more about the [limits](/help/troubleshooting/limits-and-restrictions).

```ts
httpRequest(url: string, callback: (result: HttpRequestResult) => void, options?: HttpRequestOptions): void
```

<ParamField path="url" type="string" required />

<ParamField path="callback" type="(result: HttpRequestResult) => void" required />

### httpRequestAsync

Performs an asynchronous HTTP request. TCP connect timeout is 6 seconds and total request timeout is 90 seconds. Learn more about the [limits](/help/troubleshooting/limits-and-restrictions).

## Types

### HttpRequestOptions

Advanced HTTP request options.

<a id="httprequestoptions-connectiontimeout" />
<ParamField path="connectionTimeout" type="number">
_optional_

Optional. Timeout for the TCP connection to the address in seconds. The default value is **6**. The value can be only decreased.
</ParamField>

<a id="httprequestoptions-enablesystemlog" />
<ParamField path="enableSystemLog" type="boolean">
_optional_

Optional. Whether to enable logging the POST request body. The default value is **false**.
</ParamField>

<a id="httprequestoptions-externallogging" />
<ParamField path="externalLogging" type="boolean">
_optional_

Optional. Whether to enable extended logging of the raw HTTP request and response data. The default value is **false**.
</ParamField>

<a id="httprequestoptions-headers" />
<ParamField path="headers" type="{ [key: string]: string }">
_optional_

Optional. Request headers: \{'Content-Type': 'text/html; charset=utf-8', 'User-Agent': 'YourCustomUserAgent/1.0'\}. Note that the default value for the 'User-Agent' header is **VoxEngine/1.0**.
</ParamField>

<a id="httprequestoptions-method" />
<ParamField path="method" type="string">
_optional_

Optional. HTTP request type as a string: **GET**, **POST** etc. The default value is **GET**.
</ParamField>

<a id="httprequestoptions-params" />
<ParamField path="params" type="{\n      [key: string]: string;\n    }">
_optional_

Optional. Request parameters. They can be specified in the URL itself as well.
</ParamField>

<a id="httprequestoptions-postdata" />
<ParamField path="postData" type="string | number[]">
_optional_

Optional. Raw UTF-8 encoded data string or an array of bytes in any encoding generated by [str2bytes](/reference/voxengine/net) to send as the HTTP request body when 'method' is set to **POST**, **PUT**, or **PATCH**.
</ParamField>

<a id="httprequestoptions-rawoutput" />
<ParamField path="rawOutput" type="boolean">
_optional_

Optional. Whether [HttpRequestResult.data](/reference/voxengine/net#httprequestresult) should contain a list of 1-byte numbers corresponding to the HTTP response data. If set to **false**, [HttpRequestResult.data](/reference/voxengine/net#httprequestresult) is undefined.
</ParamField>

<a id="httprequestoptions-timeout" />
<ParamField path="timeout" type="number">
_optional_

Optional. Timeout for getting a response to the request in seconds. The default value is **90**. The value can be only decreased.
</ParamField>

### HttpRequestResult

HTTP response.

<a id="httprequestresult-code" />
<ParamField path="code" type="number">
Response code. HTTP code (2xx-5xx) or one of our internal status codes

- `0`: [VoxEngine limits](/help/troubleshooting/limits-and-restrictions) are violated (e.g. HTTP request count exceeded)
- `-1`: Unknown error
- `-2`: Malformed URL
- `-3`: Host not found
- `-4`: Connection error
- `-5`: Too many redirects
- `-6`: Network error
- `-7`: Timeout
- `-8`: Internal error
- `-9`: Server response is larger than 2 MB
</ParamField>

<a id="httprequestresult-data" />
<ParamField path="data" type="number[]">
_optional_

If [HttpRequestOptions.rawOutput](/reference/voxengine/net#httprequestoptions) is true, data contains a list of 1-byte numbers corresponding to HTTP response data. If [HttpRequestOptions.rawOutput](/reference/voxengine/net#httprequestoptions) is false, data is undefined.
</ParamField>

<a id="httprequestresult-error" />
<ParamField path="error" type="string">
_optional_

In case of an error contains the error description
</ParamField>

<a id="httprequestresult-headers" />
<ParamField path="headers" type="{ key: string; value: string }[]">
_optional_

List of dictionaries with key and value fields representing HTTP headers returned by the remote server
</ParamField>

<a id="httprequestresult-rawheaders" />
<ParamField path="raw_headers" type="string">
_optional_

HTTP header string returned by the remote server, without processing
</ParamField>

<a id="httprequestresult-text" />
<ParamField path="text" type="string">
_optional_

HTTP response body if Content-Type is not binary
</ParamField>
