### NoiseSuppressionParameters

*Extends:* `_WebSocketBasedClientParameters`

[Hush.NoiseSuppression](/reference/voxengine/hush/noise-suppression) parameters. Can be passed as arguments to the `Hush.createNoiseSuppression` method.

<a id="noisesuppressionparameters-attenlimdb" />
<ParamField path="attenLimDb" type="number">

Optional. Attenuation limit in dB. **0** means no limit. The default value is **0**.
</ParamField>

#### Inherited fields

<a id="noisesuppressionparameters-privacy" />
<ParamField path="privacy" type="boolean">
_optional, inherited from _WebSocketBasedClientParameters_

Optional. Whether to enable the privacy functionality.

If privacy is enabled, the logging for the WebSocket connection is disabled.

NOTE: the default value is **false**.
</ParamField>

<a id="noisesuppressionparameters-statistics" />
<ParamField path="statistics" type="boolean">

</ParamField>

<a id="noisesuppressionparameters-trace" />
<ParamField path="trace" type="boolean">
_optional, inherited from _WebSocketBasedClientParameters_

Optional. Whether to enable the tracing functionality.

If tracing is enabled, a URL to the trace file appears in the 'websocket.created' message. The file contains all sent and received WebSocket messages in the plain text format. The file is uploaded to the S3 storage.

NOTE: enable this only for diagnostic purposes. You can provide the trace file to our support team to help investigate issues.
</ParamField>
