## Methods

### addEventListener

Adds a handler for the specified [Hush.NoiseSuppressionEvents](/reference/voxengine/hush/noise-suppression-events) or [Hush.Events](/reference/voxengine/hush/events) event. Use only functions as handlers; anything except a function leads to the error and scenario termination when a handler is called.

```ts
addEventListener(event: Hush.NoiseSuppressionEvents | Hush.Events | T, callback: (event: Hush._HushNoiseSuppressionClientEvents[T]) => any): void
```

**Parameters**

<ParamField path="event" type="Hush.NoiseSuppressionEvents | Hush.Events | T" required />

<ParamField path="callback" type="(event: Hush._HushNoiseSuppressionClientEvents[T]) => any" required />
