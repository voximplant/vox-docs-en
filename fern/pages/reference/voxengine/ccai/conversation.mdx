## Methods

### addEventListener

Adds a handler for the specified [CCAI.Events.Conversation](/reference/voxengine/ccai/events/conversation) event. Use only functions as handlers; anything except a function leads to an error and scenario termination when a handler is called.

```ts
addEventListener(event: CCAI.Events.Conversation | T, callback: (event: CCAI.Events._ConversationEvents[T]) => any): void
```
