## Methods

### addEventListener

Adds a handler for the specified [CCAI.Events.Agent](/reference/voxengine/ccai/events/agent) event. Use only functions as handlers; anything except a function leads to an error and scenario termination when a handler is called.

```ts
addEventListener(event: CCAI.Events.Agent | T, callback: (event: CCAI.Events._AgentEvents[T]) => any): void
```
