---

List of available ASR profiles. Can be passed via the `ASRParameters.profile` parameter.
Add the following line to your scenario code to use the namespace:
```
require(Modules.ASR);
```

- [Deepgram](/reference/voxengine/asr-profile-list/deepgram) — List of Deepgram ASR profiles.
- [Google](/reference/voxengine/asr-profile-list/google) — List of Google ASR profiles.
- [Microsoft](/reference/voxengine/asr-profile-list/microsoft) — List of Microsoft ASR profiles.
