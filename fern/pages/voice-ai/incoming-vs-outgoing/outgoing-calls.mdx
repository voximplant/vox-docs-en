Outgoing flows start when you trigger a routing rule manually (Control Panel) or through the Management API (`startScenarios`).
VoxEngine then starts `AppEvents.Started`.

Alternatively, you can start the outgoing flow against a call list for automated dialing [see call lists for automated outgoing calling](#call-lists-for-automated-outbound-calling).

## Outgoing Voice AI pattern

Outgoing calls have different methods depending on the destination channel (PSTN, SIP, WhatsApp, app user),
but the overall pattern is similar: trigger the call, listen for `CallEvents.Connected`, then set up the Voice AI client and media bridging.
The call methods require a `callerId`. For phone numbers this should be a verified caller ID or a purchased Voximplant number.
For WhatsApp, this should be a verified WhatsApp Business number.

```js title="Outgoing Voice AI pattern"
VoxEngine.addEventListener(AppEvents.Started, () => {
  // Retrieve information passed when the scenario was triggered
  const { destination, callerId } = JSON.parse(VoxEngine.customData());

  // Choose your call method based on the destination & desired network
  const call = VoxEngine.callPSTN(destination, callerId);
  // const call = VoxEngine.callUser({ username: destination, callerid: callerId });
  // const call = VoxEngine.callSIP(`sip:${destination}@your-sip-domain`, callerId);
  // const call = VoxEngine.callWhatsappUser({ number: destination, callerid: callerId });

  // Handle call events
  call.addEventListener(CallEvents.Disconnected, ()=>VoxEngine.terminate());
  call.addEventListener(CallEvents.Failed, ()=>VoxEngine.terminate());

  // Set up the Voice AI client and media bridging only after the call is connected
  call.addEventListener(CallEvents.Connected, async () => {
    const voiceAIClient = OpenAI.createRealtimeAPIClient({apiKey: "your-key", model: "your-realtime-model"});
    // Bridge media between the call and the Voice AI client so they can speak and hear each other
    VoxEngine.sendMediaBetween(call, voiceAIClient);
  });
});
```

### Start the outgoing flow

Choose one of these options:

#### <Icon size="5" icon="fa-sharp fa-solid fa-square-1" /> Start from the GUI (Control Panel)

In `manage.voximplant.com`, open your application, go to **Routing**, choose the rule that points to your outgoing scenario, then start it with `script_custom_data` that includes destination and caller ID.

Use `curl` to call `StartScenarios` and pass the same `script_custom_data` JSON payload from your terminal.

```bash title="CLI example via StartScenarios"
curl -X POST "https://api.voximplant.com/platform_api/StartScenarios/" \
  --data-urlencode "account_id=$VOX_ACCOUNT_ID" \
  --data-urlencode "api_key=$VOX_API_KEY" \
  --data-urlencode "rule_id=$VOX_RULE_ID" \
  --data-urlencode "script_custom_data={\"destination\":\"+15551234567\",\"callerId\":\"+15557654321\"}"
```
To call the Management API via `curl` or one of the [Management API clients](/overview/how-voximplant-works/management-api), [configure an API key](https://manage.voximplant.com/settings/service_accounts?_ga=2.264241679.1608268282.1771956490-551602791.1771956490) and create an [authorization token](/reference/management-api/authorization).


### <Icon icon="fa-duotone fa-list-check" /> Outgoing checklist

- Listen for the `AppEvents.Started` entry point
- Use `VoxEngine.customData()` to retrieve any information needed for the scenario, such as destination and caller ID to use
- Place the channel-specific call with one of the call methods (`callPSTN`, `callUser`, `callSIP`, `callWhatsappUser`)
- Listen for key call events (`Disconnected`, `Failed`, etc.) and handle as needed
- Create the Voice AI connector after `CallEvents.Connected`
- Bridge media between call and connector:
  - Use `VoxEngine.sendMediaBetween(...)` for simple two-party bridging
  - Alternatively use `call.sendMediaTo(...)` and `connector.sendMediaTo(...)` for more complex pipelines
- Invoke methods and handle events from the connector to drive your Voice AI logic

## Call lists for automated outgoing calling

When you need to dial many contacts, you can run your outgoing scenario against an uploaded CSV number table and have each scenario execution
pull the next destination.

```js title="Call list task pattern with CallList module"
require(Modules.CallList); // Enable CallList methods

VoxEngine.addEventListener(AppEvents.Started, () => {
  const task = JSON.parse(VoxEngine.customData() || "{}");
  const destination = task.destination;
  const callerId = task.callerId;

  if (!destination || !callerId) {
    CallList.reportError({
      status: "invalid_task_data",
      destination: destination || null
    });
    VoxEngine.terminate();
    return;
  }

  const call = VoxEngine.callPSTN(destination, callerId);

  call.addEventListener(CallEvents.Connected, () => {
    CallList.reportProgress({
      status: "connected",
      destination: destination
    });
    // Create/attach your Voice AI connector here.
  });

  call.addEventListener(CallEvents.Disconnected, () => {
    CallList.reportResult({
      status: "completed",
      destination: destination
    });
    VoxEngine.terminate();
  });

  call.addEventListener(CallEvents.Failed, () => {
    CallList.reportError({
      status: "failed",
      destination: destination
    });
    VoxEngine.terminate();
  });
});
```
