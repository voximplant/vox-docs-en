## Overview

This example starts a VoxEngine session, places an outgoing PSTN call, and connects the callee to Qwen Cloud after they answer.

**⬇️ Jump to the [Full VoxEngine scenario](#full-voxengine-scenario).**

## Prerequisites

- A Qwen Cloud API key stored in Voximplant [Secrets](/platform/storage/secret-storage) under `QWEN_API_KEY`.
- The example uses `qwen-audio-3.1-realtime-plus`. Change `QWEN_MODEL` if your account should use another realtime model.
- A verified or rented caller ID that can place outgoing PSTN calls.
- Start this scenario via a routing rule. For production, start the rule with the Management API.

## Custom data

Pass the destination and caller ID when starting the scenario:

```json
{"destination":"+15551234567","callerId":"+13322776633"}
```

## Alternate outgoing destinations

This example uses `VoxEngine.callPSTN(...)` for PSTN dialing. You can also route outgoing calls to other destination types in VoxEngine:

- **SIP** (`VoxEngine.callSIP`): dial a SIP URI to reach a PBX, carrier, SIP trunk, or other SIP endpoint.
- **WhatsApp** (`VoxEngine.callWhatsappUser`): place a WhatsApp Business-initiated call.
- **Voximplant users** (`VoxEngine.callUser`): call another app user in the same Voximplant application, such as a Web SDK, mobile SDK, or SIP user.

Relevant guides:

- [SIP calling options](/voice-ai/network-options/sip)
- [Voximplant users calling options](/voice-ai/network-options/web-mobile)
- [WhatsApp calling options](/voice-ai/network-options/whatsapp)

## Connect call audio

Create the Qwen client inside `CallEvents.Connected`. After `SessionUpdated`, bridge the call:

```js
VoxEngine.sendMediaBetween(call, voiceAIClient);
```
