# Supported platforms

The Voximplant platform is designed for broad compatibility across modern web, mobile, and cross-platform environments.

<Info title="The 18-month rule">
As a general rule, Voximplant maintains compatibility with all major browsers and SDK environments released within the last **18 months**.
</Info>

## Native & cross-platform SDKs

We support the following minimum platform versions across our client SDKs:

| Platform | Minimum version |
| :--- | :--- |
| **iOS** | 11.0 or later |
| **Android** | 5.0 (API level 21) or later |
| **React Native** | 0.47.0 or later |
| **Flutter** | 3.3.0 (Dart 2.18) or later |

## Web browsers

The Voximplant Web SDK is compatible with all modern desktop and mobile browsers supporting WebRTC:

| Browser | Minimum version |
| :--- | :--- |
| **Google Chrome** | 94.0 and above |
| **Yandex Browser** | 21.8 and above |
| **Microsoft Edge** | 93.0 and above |
| **Safari** | 15.0 and above |

### Mobile browsers

Voximplant web applications are fully compatible with mobile WebRTC-enabled browsers, including **Safari on iOS** and **Chrome on Android**.

## Compatibility note

While specific minimum versions are listed above, any modern browser released within the last **18 months** is expected to work seamlessly with Voximplant web applications.
